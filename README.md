# SAST

S.A.S.T. is an Anthem-inspired co-op vertical slice: a small replayable demo.

**Core loop:** Build > Fly > Fight > Loot

MVP is co-op, playable, and fun. Not a live-service launch. Not an official Anthem reboot.

## Why

We want to revive the baseline experience we all loved. This is a love letter to the community. The goal is to feel that fantasy again together, and to show that there is demand for an Anthem-style game. Many of the community is building demos separately. This is also an effort to align and compound our efforts.
