# SAST Community One-Pager

## Why

We want to revive the experience we all loved. This is a love letter to the community. The goal is to feel that fantasy again together, and to show that there is demand for an Anthem-style game.

## What

A small, replayable co-op demo you can play with friends.

**Core loop:** Build > Fly > Fight > Loot

## Who

Anyone who still longs for an Anthem-like experience. No industry politics. If you just want to play, watch, give feedback, or share, you are welcome to contribute.

## Where

- GitHub: https://github.com/MrJDR/SAST
- Discord: Coming soon
- Public updates and playable builds when ready

## When

One sprint at a time. You will see progress in public. No fake full-game launch date.

## How

Together progressively. Tell us what scratched the itch. Tell us what did not. Share clips. We are building this for ourselves. It will be far from AAA, but if there is support, we can continue to build as a community.

## This is

- A community love letter
- A small co-op vertical slice / playable demo
- Demand validation that this fantasy still matters
- Something that can strengthen community advocacy with real player signal

## This is not

- Official Anthem
- An EA/BioWare project
- A live-service reboot promise
- A demand that you code, donate, or join a studio

## How you can help

### No developer experience required

- Playtest when builds drop
- Provide us feedback
- Share this with others
- Stay kind; we are not rebuilding Anthem, but building something we can enjoy in its absence.

### Developer experience

- Join Discord and read the contributor docs on GitHub
- Claim a backlog ticket with clear acceptance criteria
- Help with Unity gameplay, tools, QA automation, build pipeline, or documentation
- Improve the core loop: Build > Fly > Fight > Loot
- Submitted work is acknowledged in contribution history (pull requests / commits)
- Accepted work is credited in the project credits
- Contributors may use their own submitted and accepted work in their portfolio

## Success

We can enjoy its gameplay with friends anytime we want. And, if we decide we need more, we can build it.
